# Maquette Pousse — Ferixu

Ouvrir `index.html` dans un navigateur. La maquette comprend quatre pages : vue d’ensemble, historique, arrosage et paramètres. Elle présente les éléments prévus dans `documentation/exigences_fonctionnelles.md`.

La maquette n’est pas connectée au backend ni au matériel : les mesures et historiques sont vides, et les commandes sont désactivées. Aucun arrosage ni changement de paramètres ne peut être effectué depuis ces pages. Les états vides sont destinés à être remplacés lors de l’intégration des données et commandes réelles.
